## Project Overview
This project is part of OSU CS Capstone and is being developed for the Oregon Department of
Fish and Wildlife (ODFW). The goal is to create an accessible tool that allows wildlife experts to
view and edit species range and habitat maps. The tool should support existing USGS maps as
well as maps developed using machine learning approaches. Accessibility is a major project
priority. The application should be easy to download, run, and use.
## Project Status
The project is in its initial development stage. An existing Python script can display habitat maps
for two species using three of eleven data sources, but most of the application will be developed
from scratch. The technology stack, architecture, development workflow, and deployment
process have not yet been finalized. These decisions will be made collaboratively by the team
and documented as the project develops.
